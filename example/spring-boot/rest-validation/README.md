# rest-validation

`JDK 21 / Spring Boot / H2 in-memory` · 공통 프로젝트 `example/spring-boot` 의 의존성을 사용합니다.

## ▶ 실행

```bash
cd example/spring-boot
./gradlew :rest-validation:bootRun
```

## ✅ 테스트

```bash
cd example/spring-boot
./gradlew :rest-validation:test
```
